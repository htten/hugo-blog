## 这是什么

一个用 Hugo 搭建的个人技术博客，托管在 GitHub Pages，域名 `htten.cc.cd`。

## 写什么

- **AI 基础**：大模型原理、训练与推理工程
- **AI 工程**：Agent 架构、可靠性设计、评测体系
- 顺带记录一些运维、工具与踩坑记录

## 技术栈

| 项 | 选择 |
| --- | --- |
| 静态站生成 | Hugo（extended，模板为本站自写） |
| 托管 | GitHub Pages + GitHub Actions 自动发布 |
| 域名 | `htten.cc.cd` |
| HTTPS | Let's Encrypt（GitHub Pages 自动签发与续期） |
